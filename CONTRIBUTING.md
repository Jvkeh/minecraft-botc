# How to Contribute
Thanks for taking the time to improve this pack, and being interested enough to do so! There are several ways to help out, and all of them are a huge assistance in making this project better and better. As a reminder, **this project is AI-free**. Contributing to this project using AI will result in a blacklist if identified, and also is just a bit messed up to do on a free human-made project!

## Reporting Issues
Even for those who are not code-minded, you can help just by playing; stress-testing the pack in weird scenarios or determining the particular environment that causes something that's a bit off is a huge help.

Check out the Issues page to either report a new bug or see if one's already open. If an issue has already been opened for the problem you've found, feel free to comment any further details you can identify on when or why it occurs, especially if it's not consistent.

Not all issues are bugs! An ultimate goal of this pack is 1:1 parity with the in-person board game, so if you find that there is a parity issue, reporting it is a huge help. This doesn't just mean missing features; for instance, in the past there was an issue where you could loosely extrapolate where the Storyteller was at night by hearing footsteps and doors opening. This isn't exactly a bug, but it is a trait that is inconsistent with the IRL game, and as such was categorized as a Parity issue.

## Writing Code
You can check out the Issues page on this repository to see a list of things that need added or changed.

As of right now, I am only accepting pull requests to resolve bug reports, not implementations of new features except as required to fix a bug. This policy is due to the personal "passion project" nature of this pack, and may change in the future.
